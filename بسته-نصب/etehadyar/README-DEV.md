# راهنمای توسعه اتحادیار

## پیش از انتشار
1. PHP نسخه ۷.۴، ۸.۱، ۸.۲ و ۸.۳ بررسی شود.
2. افزونه روی WordPress تازه و WordPress دارای محتوای قبلی فعال‌سازی شود.
3. Migrationها یک‌بار و پس از فعال‌سازی مجدد نیز بررسی شوند.
4. مرکز سلامت، Cron و تاریخچه فعالیت بررسی شوند.
5. تولید محتوای آزمایشی، تولید تصویر و بررسی اتصال سرویس‌ها اجرا شوند.
6. دسترسی کاربر نویسنده و مدیر جداگانه آزمایش شود.
7. خروجی ZIP نباید ZIP تودرتو یا فایل کلید و رمز داشته باشد.

## قواعد امنیتی
- کلیدها فقط از طریق `EAIW_Vault` ذخیره شوند.
- پاسخ خام سرویس‌ها به کاربر نمایش داده نشود.
- هر AJAX باید Nonce و Capability داشته باشد.
- عملیات سنگین باید در نسخه‌های بعدی به صف کارها منتقل شوند.
