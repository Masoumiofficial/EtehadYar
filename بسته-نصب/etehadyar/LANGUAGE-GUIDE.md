# راهنمای زبان اتحادیار

## لحن
رسمی، روان، کوتاه و دوستانه؛ بدون شوخی، اغراق یا اصطلاحات نامأنوس.

## واژه‌های استاندارد
| مفهوم | واژه استاندارد |
|---|---|
| Dashboard | پیشخوان |
| Site Brain | خرد سایت |
| Agents | یاران هوشمند |
| Factory | کارگاه محتوا |
| Guardian | نگهبان سایت |
| Nexus | خودکارسازی |
| Oracle | پیش‌بینی |
| ChatSoul | همراه سایت |
| Provider | سرویس هوش مصنوعی |
| API Key | کلید دسترسی |
| Image | تصویر |
| Video | ویدئو |
| Test | بررسی |
| Log | گزارش رویداد |

## نگارش
- نیم‌فاصله در «به‌روزرسانی»، «می‌شود» و «می‌تواند» رعایت شود.
- عنوان دکمه‌ها کوتاه و روشن باشد: «تولید محتوا»، «ذخیره تنظیمات»، «بررسی اتصال».
- پیام خطا باید علت و راه‌حل پیشنهادی را بیان کند.
- از نمایش خطای خام سرویس‌ها به کاربر خودداری شود.
